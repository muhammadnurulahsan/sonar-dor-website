# সোনার দর — ওয়েবসাইট

বাংলাদেশের (বাজুস) ও বিশ্ববাজারের সোনার দাম, প্রতি ৫ মিনিটে আপডেট, দামের গতির সংকেত আর গয়নার দাম ক্যালকুলেটর।
কোনো বিল্ড স্টেপ বা সার্ভার লাগে না; শুধু HTML, CSS আর JavaScript।

## কী নিজে থেকে চলে
- **বিশ্ববাজারের দাম:** দর্শকের ব্রাউজারে প্রতি মিনিটে লাইভ আসে (gold-api.com)। ডলারের রেট প্রতি ১৫ মিনিটে।
- **বাজুসের দাম:** `.github/workflows/update-and-deploy.yml` প্রতি ২০ মিনিটে `scripts/update-bajus.mjs` চালায়। স্ক্রিপ্টটি bajus.org থেকে দাম আনে; সেটা বন্ধ থাকলে বাজুসের দাম প্রকাশ করা কয়েকটি সাইট মিলিয়ে দেখে, অন্তত দুটি একমত হলে তবেই নতুন দাম নেয়। নতুন দাম পেলে `assets/data/bajus.json` আপডেট করে সাইট আবার প্রকাশ করে। খোলা পাতাও ১০ মিনিটের মধ্যে নতুন দাম দেখায়।
- কোনো ফাইল হাতে বদলাতে হয় না।

## একবারের সেটআপ (প্রায় ১০ মিনিট)
1. github.com-এ একটি ফ্রি অ্যাকাউন্ট খুলুন।
2. নতুন **Public** রিপোজিটরি বানান (যেমন `sonar-dor`)।
3. "uploading an existing file" লিংকে ক্লিক করে এই ফোল্ডারের ভেতরের সবকিছু (`.github` ফোল্ডারসহ) টেনে ছেড়ে দিন, তারপর **Commit changes**।
4. রিপোজিটরির **Settings → Pages → Source** থেকে **GitHub Actions** বেছে নিন।
5. **Actions** ট্যাবে গিয়ে প্রথমবার workflow চালু করার অনুমতি দিন, তারপর "Run workflow" চাপুন।
6. কয়েক মিনিট পর সাইট চালু হবে: `https://আপনার-ইউজারনেম.github.io/sonar-dor/`

নিজের ডোমেইন চাইলে Settings → Pages → Custom domain-এ বসান, আর `robots.txt` ও `sitemap.xml`-এ `YOUR-DOMAIN.com` বদলে দিন।

## ফোল্ডার
```
index.html, 404.html          পাতা
assets/js/app.js              লাইভ দাম, পূর্বাভাস, চার্ট, ক্যালকুলেটর
assets/js/config.js           কত ঘন ঘন আপডেট হবে তার সেটিংস
assets/data/bajus.json        বাজুসের দাম (রোবট নিজে আপডেট করে)
scripts/update-bajus.mjs      বাজুসের দাম আনার স্ক্রিপ্ট
.github/workflows/            স্বয়ংক্রিয় আপডেট ও প্রকাশ
DESIGN.md PRODUCT.md CLAUDE.md, .claude/skills/   ডিজাইন সিস্টেম ও Claude Code স্কিল
```

## জানা সীমাবদ্ধতা
- GitHub-এর নির্ধারিত সময়ের কাজ কখনো ১০–৩০ মিনিট দেরিতে চলে, তাই বাজুসের ঘোষণার পর দেশের দাম বদলাতে সাধারণত ২০–৪০ মিনিট লাগে।
- কোনো উৎস থেকেই দাম না পেলে আগের দামই থাকে, ভুল দাম বসে না। Actions ট্যাবের লগে প্রতিটি উৎসের ফলাফল দেখা যায়।
